# SentinelX – Border Surveillance System

## About the Project
SentinelX is a Python-based project that helps monitor border areas. It detects objects, identifies unusual activity, calculates a threat score, and sends email alerts to the user when unusual activity is detected.

## Features
1. Object detection using YOLOv8
2. Camera monitoring
3. Threat score calculation
4. Email alerts for unusual activity
5. Surveillance dashboard
6. Detection logging
7. RF device inference

## Technologies Used
- Python
- YOLOv8
- Computer Vision
